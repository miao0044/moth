## Design Context

### Users

Moth is a personal Windows desktop tool for people who work locally with Markdown, TXT, JSON, and JSONL files and who also want to read EPUB books without leaving the same focused workspace. It is used primarily with a mouse and keyboard, often for long writing or reading sessions. The core jobs are opening many local documents, moving between them quickly, editing text without visual noise, and reading reflowable books with the user's chosen typography.

### Brand Personality

Calm, restrained, and focused. Moth should feel like a dependable dark reading room: quiet enough to disappear behind the content, precise enough to reward daily use, and never decorative for decoration's sake.

### Aesthetic Direction

Continue the existing dark, minimal Moth interface and its compact Windows desktop proportions. New editor and reader states should look native to the current application rather than like a separate library, dashboard, or web page. Preserve the low-chroma palette, fine dividers, dense tab strip, and content-first hierarchy. EPUB content uses Moth's own selected fonts and spacing instead of publisher typography, so editing and reading share one coherent visual voice.

### Design Principles

- Keep content dominant: controls stay compact, contextual, and visually secondary.
- Preserve continuity: EPUB, JSONL, and text tabs share the existing shell, navigation rhythm, and settings language.
- Optimize for long sessions: readable line lengths, stable layout, comfortable leading, and predictable keyboard behavior matter more than ornament.
- Reveal complexity only when needed: narrow tabs, secondary actions, and reader navigation should adapt without crowding the default state.
- Prefer quiet precision: subtle state changes, crisp alignment, and strong legibility over gradients, glow, oversized cards, or playful motion.
